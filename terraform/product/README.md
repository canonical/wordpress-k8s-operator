# WordPress Terraform product module
<!-- vale Canonical.007-Headings-sentence-case = YES -->

This folder contains the [Terraform][Terraform] product module for WordPress. It deploys a
ready-to-use WordPress solution with the [Terraform Juju provider][Terraform Juju provider]:

- `wordpress-k8s` in the Kubernetes model given by `model_uuid`.
- `mysql` in the machine model given by `database_model_uuid`. The module offers its
  `database` endpoint and integrates WordPress with it across models.

The bundled database is optional. Set `mysql_integration` to an existing application `name` in
the Kubernetes model or to an `offer_url`, and the module integrates WordPress with it instead of
deploying its own `mysql`.

The module doesn't deploy an ingress. Set `ingress_integration` to integrate WordPress with an
existing `nginx-route` provider, such as `nginx-ingress-integrator`, and optionally
`logging_integration` to send its logs to Loki.

`risk` sets the channel risk of every bundled charm whose `channel` is left unset.

## Module structure

- **main.tf** - Defines the Juju applications, offers and integrations of the solution.
- **locals.tf** - Derives the charm channels from `risk` and selects the integration targets.
- **variables.tf** - Allows customization of the deployment, including the revision and
  OCI resources of every bundled charm.
- **outputs.tf** - Exposes the deployed `models`, the created `offers` and the deployment
  `metadata`.
- **terraform.tf** - Defines the Terraform and Juju provider versions.

## Using the WordPress product module

Always pin the `?ref=` to a released tag or a commit hash: CC008 does not allow floating
references such as branches.

```text
data "juju_model" "wordpress" {
  name  = "wordpress"
  owner = "admin"
}

data "juju_model" "database" {
  name  = "wordpress-db"
  owner = "admin"
}

module "wordpress" {
  source = "git::https://github.com/canonical/wordpress-k8s-operator//terraform/product?ref=tf-1.0.0"

  model_uuid          = data.juju_model.wordpress.uuid
  database_model_uuid = data.juju_model.database.uuid

  ingress_integration = {
    name     = "nginx-ingress-integrator"
    endpoint = "nginx-route"
  }
}
```
